# DevOS Dashboard

Production-ready React dashboard built with Vite, React 19, and modular source files.

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Structure

```text
src/
  app/          Application shell and routing
  components/   Shared UI shell and tweak controls
  data/         Dashboard mock data
  pages/        Feature pages
  styles/       Global design system and responsive layout
```

## Local Development

The dev server runs on `http://localhost:5173/` by default.
